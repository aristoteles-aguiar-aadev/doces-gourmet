# Publicação na Vercel

**Objetivo:** publicar o e-commerce no projeto `doces-gourmet`, já conectado ao repositório informado.

**Arquitetura:** manter o servidor local e adicionar uma entrada de função Node.js para Vercel. Usar Vercel Blob privado para dados e fotos, com leituras consistentes e escritas condicionais por ETag. Persistir sessões no armazenamento compartilhado para sobreviver a reinícios e múltiplas instâncias.

- [ ] Criar e conectar o armazenamento privado ao projeto existente.
- [ ] Adicionar adapter de armazenamento, sessões persistentes, uploads remotos e entrada serverless, sem gravar dados em disco na Vercel.
- [ ] Testar conflitos de gravação, inicialização concorrente, persistência das sessões e rotas HTTP existentes.
- [ ] Enviar apenas código e configuração, sem dados locais ou senhas, ao GitHub.
- [ ] Acompanhar o deploy e verificar vitrine, catálogo e painel no endereço público.

Pagamentos permanecem bloqueados até a configuração das credenciais Mercado Pago e a revisão do catálogo real. Não alterar outros projetos da conta.
